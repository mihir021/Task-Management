# Thread City Workspace Edition

MIHIR Workspace is now the homepage at `/`; `/workspace` remains a compatible link.
The separate fan landing page, suit gallery, quiz, game and newsletter are no longer routed.
Its visual identity and reusable Canvas effects are integrated into the working app.

- Shared Classic, Noir and 2099 editions, FX Full/Lite/Off and optional sound controls.
- Comic typography, paper/red/navy surfaces, web trails, interactive dashboard web and gentle page transitions.
- Theme preferences persist locally; reduced-motion settings are respected.
- Tasks, repository tracking, work logs, Scripts, Ports Monitoring and password protection retain their existing APIs.
- The database and local runner pairing remain unchanged.

Run `npm start` for the full application. `npm run build` creates the Vercel client build.
`src/workspace/WorkspaceExperience.tsx` owns the shared controls and dashboard hero.
`src/workspace/thread-workspace.css` owns the workspace palette, layout and animation styling.
Reusable effects and their tuning remain in `src/fan/Effects.tsx` and `src/fan/config.ts`.
Archived fan-page source remains available in Git history and unreferenced source files.
